# Interactive Coffee Sales Dashboard ☕📊

## 📌 Project Overview
An end-to-end data analysis and visualization project built in **Microsoft Excel**. This project demonstrates how to transform raw, disconnected transactional data and disparate lookup tables into a fully interactive executive dashboard to monitor sales performance, regional revenue trends, and top customer metrics.

---

## 🚀 Key Business Insights & Technical Highlights
* **Automated Data Integration:** Used advanced `XLOOKUP` and dynamic `INDEX/MATCH` functions to bridge disparate customer, product, and order tables into a unified master database.
* **Data Cleaning & Structure:** Converted ranges into dynamic Excel Tables (`Ctrl + T`) to automate pivot table ranges, ensure zero duplication, and enforce rigorous data integrity.
* **Advanced Formatting:** Applied custom date formatting (`DD-MMM-YYYY`), metric package sizing (`0.0" kg"`), and US Dollar currency formatting for enhanced readability.
* **Interactive Visualization Suite:** Designed customized pivot charts tracking total sales over time, regional performance across international markets, and top 5 customer accounts.
* **Global Report Connections:** Integrated a customized date **Timeline** and multi-attribute **Slicers** (*Roast Type, Package Size, Loyalty Program Status*) connected across all visuals for real-time, dynamic data exploration.

---

## 🛠️ Tech Stack & Tools
* **Data Processing & Modeling:** Microsoft Excel (`XLOOKUP`, `INDEX/MATCH`, Nested `IF` Functions, Excel Tables, Data Validation)
* **Data Visualization & BI:** Excel Pivot Tables, Pivot Charts, Custom Timelines, and Interactive Slicers
